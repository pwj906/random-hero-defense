# 랜덤 히어로 서바이버 — 디자인 요청서 2 (GPT 전달용)

## 무엇을 만드나
v16·v17에 새로 생긴 것들은 지금 코드로 그린 도형이나 이모지로 표시하고 있다. 그 자리에 넣을 그림을 요청한다.
- 금화·상점·병원·복권
- 보급소 등급
- 황금 고블린
- 역할(딜러·전사·제어·지원)과 조합 보너스
- 버프·상태 이상
- 장판 기술

이전에 보낸 이펙트 zip(fx/props)과 같은 규칙으로 만든다.

## 공통 규칙
- **스타일:** 지금 게임 그림과 같은 카툰풍. 굵은 외곽선, 선명한 색, 작게 보여도 읽히는 단순한 실루엣.
- **배경:** 어두운 우주(#0a0e1f) 위에 놓인다. 투명 배경 PNG로, 글자는 넣지 않는다.
- **애니메이션:** 가로 한 줄 스프라이트 시트로 만든다. 프레임을 왼쪽→오른쪽으로 간격 없이 붙인다.
  - 파일 이름 끝 `_N`이 프레임 수다. 예: `slot_spin_8.png`.
  - 한 장짜리 그림은 숫자 없이 이름만 쓴다.
- **중심점:** 모든 프레임에서 칸 정가운데가 중심이다. 건물은 바닥 가운데가 칸 아래쪽 90% 지점에 오게 한다.
- **방향:** 방향이 있는 그림은 오른쪽(→)을 보게 그린다.

## 보낼 때 폴더 구조 (zip 하나, 나눠 보내도 됨)
```
building/  ui/  enemy/  role/  comp/  buff/  status/  zone/  item/
```
**우선순위: A(건물) → B(금화·슬롯) → D(역할) → C(황금 고블린) → F(장판) → E → G.**
A만 먼저 와도 바로 넣을 수 있다.
