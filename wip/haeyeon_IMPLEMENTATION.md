# 해연 — 행성 및 1·2단계 개발 전달

행성 ID `haeyeon`, 표시명 ‘해연’. 심해 종족, 산호·조개 군도와 발광 해구가 특징. 최상위 우주 영웅은 포세이돈으로 확정 방향이나 이번 패키지에는 행성·1·2단계만 포함한다. 기존 파우니아/몽글성과 구분하며 신규 특수조합은 아직 배정하지 않는다.

행성 PNG는 투명 구형 이미지. 행성 선택·영웅 카드·행성별 강화 UI에 등록한다. 1·2단계는 **기존 행성별 업그레이드**를 적용하며 특수조합 개별 강화 대상이 아니다. 해연만 다른 행성보다 조합 선택지가 많아지지 않도록 추후 조합 수를 맞춘다.

## 공통 파일·동작

영웅별 대기 2장·기본공격 4장·특수 6장, 각 512×512 투명 RGBA. 오른쪽 3/4, 발 기준 y=460, 피벗은 manifest.json. 1칸 점유, 이동·피격·사망 프레임 없음. 캐릭터에 궤적·그림자·등급 원형·UI 글자를 굽지 않았다. 이펙트는 fx의 별도 PNG를 사용한다.

대기 500/500ms 반복. 기본 90/90/100/140ms, 3번째 프레임 시작 180ms에서 40ms 후인 **220ms 판정**. 특수 150/150/120/120/180/180ms, 5번째 프레임 시작 **540ms 판정**. 그림을 바꿀 때 bbox 기준으로 캐릭터 크기를 재조정하지 않는다. 실제 공격 간격은 아래 값과 게임 밸런스에 맞추고 프레임 지속시간을 피해 횟수로 해석하지 않는다.

## 1단계 — 진주먹 꼬마

ID `pearlpunch`, 단계 우리 집(기존 엔진 t=0). 작은 조개 몸·머리의 푸른 진주·두 조개 주먹. 웃긴 생활 히어로. 근접 단일 딜러.

기본 ‘조개권’: 간격 1.4초, 사거리 1.5칸 제안. 사거리 내 경로 진행률 가장 높은 적을 선택, 타격 시 생존·사거리 재확인. 현재 공격력 A×1, 한 명만 타격. shell_hit를 명중 위치에 180ms. 주먹에서 적까지 짧은 ivory 잔상/연결선을 120ms 보여주되 투사체로 구현하지 않는다. 대상 사망·범위 이탈이면 빗나감, 재타게팅 없음.

특수 ‘진주 쌍권’: 쿨타임 최종 60초 제안, 같은 사거리의 단일 적 A×3.2 한 번. 양 주먹이라도 각각 피해를 두 번 주지 않는다. shell_double_hit 250ms. 기절·버프·재화·적 모으기는 부여하지 않는다. 낮은 단계가 상위 지원 영웅을 대체하지 않게 한다.

## 2단계 — 집게창병

ID `clawlancer`, 단계 우리 동네(t=1). 청록 갑각과 주황 집게 방패·짧은 창, 작은 게 다리. 근접 단일/좁은 범위 딜러.

기본 ‘집게창 찌르기’: 간격 1.2초, 사거리 2칸 제안. 지정 적에게 A×1 한 번, spear_hit 160ms. 관통 판정 없음. 창의 시각적 끝에서 지정 적 위치로 짧은 창끝 잔상만 연결. 220ms 타격 때 적 생존·실제 거리 재검사.

특수 ‘집게 휩쓸기’: 쿨타임 최종 60초 제안. 시전 시작에 공격 방향 저장. 540ms 캐릭터 기준 반경 2칸·각도 90도 부채꼴의 살아 있는 적에게 각각 A×3 피해 1회, 최대 3명(경로 진행률 우선). 지정 적 추가 피해 없음. claw_swipe를 해당 방향으로 220ms 확장·감쇠. 밀치기·모으기·마비·아군 버프 없음. 방패 외형은 설정 요소로, 아군 피격이 없는 게임에 체력/방어 시스템을 추가하지 않는다.

## 강화·연출·검증

위 배율의 A는 해연 행성별 강화 및 기존 공격력 계산을 거친 현재 공격력. 기본 baseDamage는 같은 단계 다른 행성의 기준을 사용한다. 특별히 강한 고정 수치를 이 패키지에서 부여하지 않는다. 공통 0.7 쿨타임 보정 적용 시 60초가 42초가 되므로 최종 쿨타임 정책 확인.

낮은 단계이므로 전장 강림 피해·상시 신격 오라·컷인 없음. 소환 시 기존 작은 팝 연출만 사용. 반복 기본공격 섬광/화면 흔들림 없음, 특수도 캐릭터 주변 작은 효과와 짧은 타격음으로 충분하다.

판정은 `attackId:targetId` 또는 `castId:targetId`로 1회. 렌더 프레임/이펙트 중복이 추가 피해를 만들지 않는다. 배속·저FPS·대상 사망·거리 이탈·일시정지 복귀 테스트. 집게창병 특수 최대 3명·부채꼴 뒤쪽 제외 확인. 행성별 강화가 두 영웅에 함께 적용되며 다른 행성에는 적용되지 않는지 확인.

수치·네이밍은 구현 초안. 에셋 및 ZIP 검증 후 전달하며 실제 게임 연결·플레이테스트는 수행하지 않았다.
