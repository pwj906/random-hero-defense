# 랜덤 히어로 서바이버 — 공격 이펙트·연출 디자인 요청서 (GPT 전달용)

## 무엇을 만드나
뱀서류 게임 '랜덤 히어로 서바이버'의 전투 이펙트와 연출 그림이 필요하다. 지금은 코드로 그린 동그라미·선만 있어서 타격감이 약하다.
영웅 74명이 자동으로 공격하고, 공격 방식은 7종류다. 이펙트는 **종류별로 하나씩** 만들고, 게임이 행성 색으로 물들여 쓴다.

## 공통 규칙
- 스타일: 기존 영웅 그림과 같은 카툰풍. 굵고 단순한 모양, 작게 보여도 읽히게. 빛나는 핵 + 바깥 테두리 2단 구성.
- 배경: 어두운 우주(#0a0e1f). 투명 배경 PNG를 쓴다.
- **색: A·B 묶음은 흰색~밝은 회색으로만 그린다.** 진한 부분은 회색, 빛나는 핵은 흰색으로. 게임이 행성 색(파랑·주황·초록 등)을 곱해서 물들인다. C~E 묶음은 색을 넣어도 된다(적힌 색 참고).
- 애니메이션: **가로 한 줄 스프라이트 시트**(프레임을 왼쪽→오른쪽으로 나란히, 간격 없이)로 만든다.
  - 프레임 칸 크기는 표에 적힌 대로 한다. 파일 이름 끝에 프레임 수를 붙인다(예: `hit_shot_6.png` = 6프레임).
  - 모든 프레임에서 **중심점(맞는 지점)이 칸 정가운데**에 오게 한다.
  - 마지막 프레임은 거의 사라진 상태로 끝낸다(게임이 반복하지 않고 한 번 재생 후 지움). 단, '반복'이라고 적힌 것은 첫 프레임과 자연스럽게 이어지게 만든다.
- 방향: 방향이 있는 것(투사체·베기·부채꼴)은 **오른쪽(→)을 향하게** 그린다. 게임이 돌려서 쓴다.
- 글자는 넣지 않는다.

## F. 여유 있으면 (구역 꾸밈 소품)
구역 6개마다 바닥에 흩뿌릴 소품 4개씩이다. 128×128 한 장씩, 위에서 약간 비스듬히 본 시점으로, 그림자는 넣지 않는다.
- 별빛 평원 `plain`: 작은 크레이터, 별 결정, 부서진 위성 조각, 우주 바위
- 불꽃 협곡 `lava`: 용암 바위, 불 뿜는 틈, 검은 뿔 바위, 화산재 더미
- 얼음 설원 `snow`: 눈 덮인 침엽수, 얼음 결정 기둥, 눈더미, 얼어붙은 바위
- 태고의 숲 `forest`: 큰 나무(위에서 본 둥근 수관), 버섯 무리, 꽃 덤불, 쓰러진 통나무
- 심해 해구 `deep`: 산호, 해초, 조개, 거품 나는 바위
- 기계 폐허 `ruin`: 톱니바퀴, 부서진 로봇 팔, 철판 조각, 깜빡이는 단말기

## 보낼 때 폴더 구조 (zip 하나, 나눠 보내도 됨)
```
fx/attack/   (A 묶음)
fx/special/  (B 묶음)
fx/common/   (C 묶음)
fx/reward/   (D 묶음)
fx/map/      (E 묶음)
props/<구역>/<이름>.png   (F 묶음, 예: props/lava/rock.png)
```
**우선순위: A → D → B → C → E → F.** A만 먼저 와도 바로 넣을 수 있다.
